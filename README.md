# 밀양국제요가컨퍼런스 방문객 안내앱 (모바일 전용, 3개 국어)

## 구조
- index.html : 앱 본체 (모바일 480px 기준, PC에서는 가운데 폰 화면으로 표시)
- lang/ko.js · en.js · hi.js : 기본 텍스트 (일정·티켓·FAQ·오는길 등)
- lang/ko.v2.js · en.v2.js · hi.v2.js : 이 앱 전용 텍스트 (요가 몰라도 되는 하루, 코스, 골든만다라, 지도 라벨, 진입로 스텝, 22번 버스, 부스 35~40)
- img/ : 이미지 (포스터·강사·지난 사진·로고 등)

## 화면
홈(포스터·카운트다운·요가 안 해도 되는 하루·코스 3종·골든만다라 티저·사진 스팟·소개) / 놀거리(행사장 지도 SVG + 부스 1~40 목록, 번호 탭 → 하단 시트) / 일정 / 오는길(주소·지도 링크·진입로→주차→행사장 스텝 카드·셔틀·22번 버스·숙소) / 안내(무료 프로그램·티켓·준비물·우천·FAQ·문의)

## 이미지 교체 포인트 (챗GPT 생성본으로 교체)
- 행사장 지도: 현재 index.html 의 mapSVG() 가 그리는 SVG 약도. 일러스트로 바꾸려면 `.mapwrap` 안에 <img> 를 깔고 부스 번호 좌표(BP)를 그 위에 오버레이하면 됨
- 진입로 스텝 이미지: stepSVG() 자리. `img/step0.jpg ~ step5.jpg` 를 넣고 stepSVG(k) 를 `<img src="img/${k}.jpg">` 로 바꾸면 됨

## 배포
폴더째 Vercel 에 업로드 (Framework: Other). 주소는 vercel.json 없이도 동작.
